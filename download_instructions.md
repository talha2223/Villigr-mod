# AI Villager Mod Download

The mod has been successfully compiled and is ready for use!

You can download the compiled `.jar` file directly from the repository at the following path:

**`release/ai-villager-mod-1.0.0.jar`**

### Installation Instructions
1. Ensure you have **Minecraft 1.21.7** installed.
2. Ensure you have the **Fabric Loader** (0.16.0 or higher) installed for 1.21.7.
3. Download the `ai-villager-mod-1.0.0.jar` file from the `release` folder.
4. Place the `.jar` file into your Minecraft `.minecraft/mods` folder.
5. Launch the game. The first time you launch, it will generate a config file at `.minecraft/config/aivillager.json`. Open this file and paste your Gemini API key inside.
